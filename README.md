# Experiment 3: Iterative Prompt Refinement

## Aim
To demonstrate how iterative prompt refinement improves an LLM's explanation of photosynthesis for a 10-year-old child.

## Problem Statement
Develop a Python program that sends three progressively refined prompts to an LLM, captures the responses, and analyses the improvements.

## Technologies Used
- Python
- Google Gemini AI
- Google Gen AI SDK

## Prompt Iterations

### Iteration 0: Baseline
Explain photosynthesis to a 10-year-old.

### Iteration 1: First Refinement
Adds a friendly teacher role, a simple analogy, short sentences, and a restriction against technical jargon.

### Iteration 2: Second Refinement
Adds a memory trick and a text-based diagram description to improve understanding and recall.

## Algorithm
1. Initialize the Gemini client using an API key.
2. Define a function to send prompts to the LLM.
3. Create three prompt versions.
4. Generate and display a response for each version.
5. Analyse the improvements after each iteration.
6. Save all prompts, responses, and analyses to a text file.
7. Print a final summary.

## Installation

```bash
pip install -r requirements.txt
```

## Configuration
Set the `GEMINI_API_KEY` environment variable. Never commit API keys to GitHub.

## Execution

```bash
python src/main.py
```

## Expected Output
- Iteration 0 prompt and response.
- Iteration 1 prompt and response.
- Iteration 2 prompt and response.
- Analysis after each iteration.
- Final summary saved in `output/refinement_results.txt`.

## Result
The program demonstrates how successive prompt modifications can guide an LLM toward simpler, more engaging, and more memorable explanations.

## Conclusion
Iterative prompt refinement improves instructions step by step. Analogies, simple language, memory tricks, and diagram descriptions can make scientific explanations more accessible to children. Actual improvements depend on the responses generated by the model.
